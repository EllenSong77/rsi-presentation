# RSI 递归自我改进 · 智谱

20 页交互式 HTML 演示，介绍 AI 如何帮助改进后续 AI。

[打开演示](https://ellensong77.github.io/rsi-presentation/)

## 内容

- 模型、工具与工作流程的区别，以及递归关系。
- 四种技术路线的交互流程图与生命周期位置。
- 智谱 GLM-5.1 的向量数据库、GPU 计算程序优化案例。
- 智谱 GLM-5.3 中 AI 参与训练任务环境生成与验证的实践。
- AlphaEvolve、Darwin Gödel Machine、Hyperagents 的公开案例。
- 现有限制与未来研究方向。

## 操作

左右方向键翻页，O 打开目录，F 全屏，B 黑屏暂停。技术路线可以切换和逐步高亮，报销原理用例可按环节查看。

也可以下载 `index.html`，用浏览器离线打开。页面和 Logo 自包含，无需安装依赖或调用 API。打开原始来源链接需要网络。

正文附原始来源。案例数字按作者或厂商公开材料呈现，解释性示意与案例证据分别标注。Logo 使用提供的原始文件，按深浅背景分别展示。

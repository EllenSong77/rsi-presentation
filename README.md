# RSI 递归自我改进 · 智谱

交互式 HTML 演示，介绍 RSI 的原理、公开研究、企业实践与未来趋势。

## 访问

[打开演示](https://ellensong77.github.io/rsi-presentation/)

也可以下载 `index.html` 后用浏览器直接打开。页面与 Logo 自包含，无需安装依赖。

## 操作

- 左右方向键翻页，O 打开目录，F 全屏。
- B 黑屏暂停，任意键恢复。
- 改进闭环支持逐步查看，也可直接选择环节。
- 互动实验均为本地模拟，不调用 API。

正文附原始来源。研究结果依照对应公开材料，模拟指标与方案场景均明确标注。Logo 使用提供的原始文件，按深浅背景分别展示。

# RSI 递归自我改进 · 智谱

22 页交互式 HTML 演示，围绕递归自我改进串联原理、技术、智谱公开实践与未来方向。

[打开演示](https://ellensong77.github.io/rsi-presentation/)

## 内容

- 从 RSI 的概念与递归关系切入，介绍模型、工具和研发方法的自我改进。
- 解释训练阶段、递归关系，以及模型能够参与的研发工作。
- 四条技术路线与一个包含输入、行动、输出的训练改进示例。
- 自我判断、何时停止、自主纠错，以及伦理与治理的作用。
- GLM-5.3 训练任务环境构建与验证、GLM-5.1 连续工程优化。
- AlphaEvolve、DGM、Hyperagents 与下一步研究问题。

每页包含到下一页的衔接问题。研究目标、公开案例和解释性示意分别标明。

## 操作

左右方向键翻页，O 打开目录，F 全屏，B 黑屏暂停。

技术路线可以切换并逐步高亮，训练示例可按环节查看。点击“连续阅读”展开所有页面、全部路线及六个训练环节，适合自行阅读；点击“分页演示”返回幻灯片。

也可以下载 `index.html`，用浏览器离线打开。页面与 Logo 自包含，无需安装依赖或调用 API。打开来源链接需要网络。

正文附原始来源。案例数字按作者或厂商公开材料呈现。Logo 使用提供的原始文件，按深浅背景展示。

# RSI 递归自我改进 · 智谱

21 页交互式 HTML 演示，通过四个问题介绍 RSI 的原理、发展条件、公开实践和未来方向。

[打开演示](https://ellensong77.github.io/rsi-presentation/)

## 四章结构

1. **RSI 是什么，它怎样运转？** 区分模型、工作材料和工具流程，用具体闭环理解递归关系。
2. **为什么现在受到关注？** 理解改进需求、模型执行能力和反馈条件，以及经验如何保留。
3. **业界已经做到了什么？** 通过 GLM-5.1、GLM-5.3、AlphaEvolve 和 DGM 的公开案例理解方法与证据。
4. **接下来可能怎样发展？** 从评价、纠错和停止等难点推导未来方向。

技术方法跟随案例解释。全程使用三个问题：改进的是什么、凭什么判断变好了、如何帮助下一轮改进。

## 使用

- 首页四个问题可以直接跳转章节。
- 方向键翻页，O 打开目录，F 全屏，B 黑屏暂停。
- 闭环示例支持五个步骤切换；进化式搜索支持三个阶段切换。
- “连续阅读”展开全部页面与所有示例步骤，适合独立阅读。
- 页面可在电脑和手机查看，也可下载 `index.html` 离线打开。

内容、图示与原始 Logo 自包含，无需安装依赖或调用 API。打开来源链接需要网络。案例引用原始论文与官方资料，教学模拟明确标注，不将模拟数字当作实测结果。
